# Portfolio_2026

My personal developer portfolio, built with Next.js 16 (App Router), React 19, and TypeScript.

The site pulls my project list live from the GitHub API (via Octokit) and renders each repo's README directly on the page with react-markdown, so it always reflects the current state of my work without manual updates.

## Tech Stack

- Next.js 16 (App Router)
- React 19 + TypeScript
- Tailwind CSS 4
- Octokit (GitHub API client)
- react-markdown

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view it locally.

## Deployment

Deployed on Vercel.
